# 🌙 Low Light Image Enhancement System

## 📌 Overview
This project is a **Low Light Image Enhancement System** that improves the visibility of images captured in poor lighting conditions. It processes dark images and enhances brightness, contrast, and overall clarity using image processing techniques.

The goal is to make low-light images more usable for real-world applications like surveillance, photography, and analysis.

---

## 🚀 Features
- Enhance low-light images automatically
- Improve brightness and contrast
- Reduce noise in dark images
- Save enhanced output images
- Simple and easy-to-use workflow

---

## 🛠️ Tech Stack
- Python
- OpenCV
- NumPy

---

## 📂 Project Structure
```

Foundation_Project/
│── input_images/        # Contains low-light input images
│── output_images/       # Stores enhanced images
│── main.py              # Main execution file
│── utils.py             # Helper functions
│── README.md

````

---

## ⚙️ Installation

1. Clone the repository:
```bash
git clone https://github.com/23BCE0066/Foundation_Project.git
````

2. Navigate to the project folder:

```bash
cd Foundation_Project
```

3. Install required dependencies:

```bash
pip install opencv-python numpy
```

---

## ▶️ How to Run

```bash
python main.py
```

* Place your low-light images inside the `input_images/` folder
* The enhanced images will be saved in the `output_images/` folder
